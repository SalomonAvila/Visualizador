1. Arreglos Unidimensionales (1D)

Declaración y recorrido clásico con ciclo for:

int numeros[5] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++) {
    cout << numeros[i] << endl; // Acceso por indice [0] al [4]
}

2. Matrices Bidimensionales (2D)

Declaración y recorrido con ciclos anidados (fila y columna):

int matriz[3][3];
for (int f = 0; f < 3; f++) {
    for (int c = 0; c < 3; c++) {
        matriz[f][c] = (f + 1) * (c + 1);
    }
}

3. Estructuras (struct) y Arreglos de Structs

Definición de registros y acceso por punto .:

struct Alumno {
    string nombre;
    int edad;
    float nota;
};

Alumno clase[10]; // Arreglo de 10 alumnos
clase[0].nombre = "Sofia";
clase[0].edad = 19;
clase[0].nota = 9.5;

4. Archivos (fstream), parseo con getline por comas y atoi

Lectura estándar de archivos CSV de texto:

#include <fstream>
#include <cstdlib>

ifstream archivo("estudiantes.csv");
ofstream reporte("salida.txt");

string campo1, campo2Str;
// getline lee hasta encontrar la coma ','
while (getline(archivo, campo1, ',')) {
    getline(archivo, campo2Str); // lee el resto de la linea hasta el salto

    int valor = atoi(campo2Str.c_str()); // convierte string a int
    reporte << "Guardado: " << campo1 << " " << valor << endl;
}

archivo.close();
reporte.close();
